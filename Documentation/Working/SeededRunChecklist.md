# Seeded dashboard release gate

Use this checklist before and during the internal beta. Run each case once through the dashboard and once through the Debug console (`-debugConsole`). The resulting age, stats, cash, history headlines, pending-event state, and terminal state must match for the same seed and choices.

| Seed | Policy | Years | Verify |
| --- | --- | ---: | --- |
| 101 | Balanced | 20 | Creation, each domain, result sheets, save/relaunch |
| 202 | Grind | 50 | School progression, cash pressure, bounded history |
| 303 | Social | 50 | Partner and relationship consequences |
| 404 | Survival | 80 | Health pressure and recovery choices |
| 505 | Balanced | 80 | Long-run determinism and terminal review |

## Per-run record

- Seed, origin preset, starting age, and ending age.
- Every event headline and selected choice.
- First boring year and the action that felt inconsequential.
- Any money or recovery confusion.
- Whether save/relaunch preserved the exact life.

Do not change simulation rules based on a single run. Promote only recurring feedback to a release blocker.
